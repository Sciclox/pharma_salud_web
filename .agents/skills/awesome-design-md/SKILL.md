# Awesome Design System Skill (Apple, Airbnb, Linear)

This skill provides ready-to-use design systems and rules inspired by Apple, Airbnb, and Linear. It allows you to generate top-tier, premium user interfaces by adhering to three distinct visual languages.

## Available Design Languages

1. **Apple Design System** (Photography-First, Minimalist, Action Blue)
   - **Key Color**: Action Blue `#0066cc` / Focus Blue `#0071e3` / Sky Blue `#2997ff`
   - **Surfaces**: Canvas `#ffffff` / Parchment `#f5f5f7` / Dark Tile `#1d1d1f`
   - **Typography**: SF Pro Display / SF Pro Text with negative tracking (`letter-spacing: -0.02em` to `-0.04em` on displays).
   - **Best For**: High-end marketing pages, landing pages, and showcases where the focus is on products, layouts, and high-fidelity text.

2. **Airbnb Design System** (Warm, Friendly Marketplace, Rausch Red)
   - **Key Color**: Airbnb Rausch `#ff385c` / Luxe `#460479` / Plus `#92174d`
   - **Surfaces**: Canvas `#ffffff` / Soft Gray `#f7f7f7` / Border `#dddddd`
   - **Typography**: Airbnb Cereal VF / Circular with light, readable weights (no heavy black displays).
   - **Rounding**: Generous and friendly (`14px` to `20px` border-radius, pill buttons).
   - **Best For**: E-commerce, customer-facing portals, marketplaces, directories, and welcoming dashboard interfaces.

3. **Linear Design System** (Precision, Dark-Mode Native, Lavender Blue)
   - **Key Color**: Lavender-Blue `#5e6ad2` / Focus Purple `#828fff`
   - **Surfaces**: Canvas `#010102` / Surface-1 `#0f1011` / Surface-2 `#141516` / Hairline Border `#23252a`
   - **Typography**: Linear Display / Linear Text with light tracking and crisp alignment.
   - **Best For**: Developer tools, dashboard admin views, SaaS control panels, technical logs, audit trails, and high-density information displays.

## Guidelines for Use

- When building or refactoring components, ask yourself which of these three aesthetics matches the user's intent or current product context.
- Avoid mixing design systems within the same view; choose one system and stick to its specific spacing, rounding, typography, and color tokens.
